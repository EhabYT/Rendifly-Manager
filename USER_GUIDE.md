## Español

### Empieza aquí

1. Consulta la [descarga y su disponibilidad](README.md#rendifly-download).
2. Cuando tengas el instalador oficial, ejecútalo y sigue el asistente de Windows.
3. Abre Rendifly Manager y completa la bienvenida. Puedes indicar cómo quieres que te llame y elegir una sección inicial.
4. En **Configuración**, elige idioma, apariencia y comportamiento de la ventana.
5. Abre **Inicio** para ver el estado general de tu PC.

**Requisitos:** Windows 10 o Windows 11. Algunas métricas dependen del hardware y de los datos disponibles en Windows.

### Encuentra lo que necesitas

| Quiero… | Abre… | Qué puedes hacer |
| --- | --- | --- |
| Entender cómo está mi PC | Inicio y Rendimiento | Consultar CPU, RAM, GPU, almacenamiento, red y recomendaciones. |
| Revisar aplicaciones abiertas | Procesos | Buscar aplicaciones, consultar su consumo y cerrar las que corresponda. |
| Revisar temporales | Optimización → Limpieza | Analizar, revisar el resultado y ejecutar la limpieza. |
| Gestionar qué inicia con Windows | Optimización → Inicio | Consultar aplicaciones de inicio y las opciones disponibles para administrarlas. |
| Preparar un entorno de trabajo o juego | Perfiles | Elegir aplicaciones que el perfil intentará mantener cerradas. |
| Cambiar el plan de energía | Energía | Consultar y seleccionar planes de energía de Windows. |
| Conocer los componentes | Sistema → Mi PC | Revisar información del hardware y explicaciones de sus datos. |
| Consultar drivers | Sistema → Drivers | Ver información y acceder a herramientas oficiales o Windows Update. |
| Encontrar un ajuste de Windows | Sistema → Ajustes de Windows | Consultar explicaciones y abrir la configuración correspondiente. |
| Hacer una pregunta sobre el equipo | Pregúntale a Rendifly | Usar el asistente local con información del equipo. |
| Cambiar idioma o apariencia | Configuración | Ajustar preferencias, temas, acento y tamaño de la interfaz. |

### Antes de aplicar una acción

- **Procesos:** guarda tu trabajo antes de cerrar una aplicación. El cierre puede finalizar tareas que estén en curso.
- **Limpieza:** comienza por el análisis y revisa los archivos temporales elegibles y el espacio estimado antes de ejecutar la limpieza.
- **Inicio de aplicaciones:** deshabilitar una entrada cambia su inicio automático; no equivale a desinstalar el programa. Algunas operaciones se realizan desde Configuración de Windows.
- **Energía:** seleccionar un plan cambia el plan activo de Windows y puede modificar el equilibrio entre consumo y rendimiento.
- **Perfiles:** revisa las aplicaciones seleccionadas. Mientras el perfil esté activo, Rendifly puede intentar cerrarlas nuevamente si vuelven a abrirse. Desactiva el perfil cuando dejes de necesitarlo.

### Preguntas frecuentes

**¿Por qué falta alguna temperatura o métrica?** La información disponible depende del hardware, sus controladores y Windows. La aplicación puede mostrar «No disponible» cuando no puede obtener un dato.

**¿El asistente usa IA externa?** B1 ofrece un asistente local. Los proveedores externos de IA están deshabilitados en la interfaz.

**¿Actualiza los drivers automáticamente?** No. Muestra información y facilita el acceso a herramientas oficiales.

**¿Cómo cierro Rendifly por completo?** Si activaste el cierre a bandeja, la X puede ocultar la ventana. Usa **Salir** en la bandeja o la opción de cerrar la aplicación.

**¿Cómo lo desinstalo?** Busca Rendifly Manager en las aplicaciones instaladas de Configuración de Windows y selecciona **Desinstalar**.

**¿Dónde reporto un problema?** En [errores y problemas de instalación](https://github.com/rendiflypcmanager-web/Rendifly-Manager/issues/new?template=bug_report.md). Para ideas, usa [sugerencias](https://github.com/rendiflypcmanager-web/Rendifly-Manager/issues/new?template=feature_request.md). Los reportes son públicos; elimina datos personales de las capturas y registros.

## English

### Start here

1. Check [download availability](README.md#rendifly-download).
2. Once you have the official installer, run it and follow the Windows setup wizard.
3. Open Rendifly Manager and complete the welcome steps. You can choose a name and an initial section.
4. In **Settings**, choose your language, appearance, and window behavior.
5. Open **Home** for an overview of your PC.

**Requirements:** Windows 10 or Windows 11. Some metrics depend on your hardware and the information available in Windows.

### Find what you need

| I want to… | Open… | What you can do |
| --- | --- | --- |
| Understand my PC's status | Home and Performance | Check CPU, RAM, GPU, storage, network activity, and recommendations. |
| Review running applications | Processes | Search applications, check resource usage, and close appropriate applications. |
| Review temporary files | Optimization → Cleanup | Scan, review the results, and run cleanup. |
| Manage what starts with Windows | Optimization → Startup | Review startup applications and available management options. |
| Prepare for work or gaming | Profiles | Choose applications that the profile will try to keep closed. |
| Change the power plan | Power | Review and select Windows power plans. |
| Learn about the components | System → My PC | Review hardware information and explanations. |
| Check drivers | System → Drivers | View information and access official tools or Windows Update. |
| Find a Windows setting | System → Windows Settings | Read explanations and open the relevant settings page. |
| Ask about my computer | Ask Rendifly | Use the local assistant with PC information. |
| Change language or appearance | Settings | Adjust preferences, themes, accent color, and interface size. |

### Before applying an action

- **Processes:** save your work before closing an application. Closing it may end tasks that are in progress.
- **Cleanup:** scan first and review eligible temporary files and estimated space before running cleanup.
- **Startup apps:** disabling an entry changes automatic startup; it does not uninstall the application. Some operations are handled in Windows Settings.
- **Power:** selecting a plan changes the active Windows power plan and may affect the balance between power use and performance.
- **Profiles:** review selected applications. While a profile is active, Rendifly may attempt to close them again if they reopen. Disable the profile when you no longer need it.

### Frequently asked questions

**Why is a temperature or metric missing?** Available information depends on hardware, drivers, and Windows. The application may show “Not available” when it cannot obtain a value.

**Does the assistant use external AI?** B1 provides a local assistant. External AI providers are disabled in the interface.

**Does it update drivers automatically?** No. It displays information and provides access to official tools.

**How do I fully close Rendifly?** If close-to-tray is enabled, the X may hide the window. Use **Exit** in the system tray or the close application option.

**How do I uninstall it?** Find Rendifly Manager in the installed apps list in Windows Settings and select **Uninstall**.

**Where do I report a problem?** Use [bug and installation reports](https://github.com/rendiflypcmanager-web/Rendifly-Manager/issues/new?template=bug_report.md). For ideas, use [feature requests](https://github.com/rendiflypcmanager-web/Rendifly-Manager/issues/new?template=feature_request.md). Reports are public; remove personal information from screenshots and logs.
